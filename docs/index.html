Clipping Agent

Clipping Agent is an open-source command-line tool, part of the editorvideo-ai repository, that runs on the user's own computer. It cuts short-form video clips from footage the user supplies and, on the user's explicit instruction, publishes them to social platforms (including TikTok, through the TikTok Content Posting API) using the user's own accounts.
